# Jalara Typography

## Official wordmark

The wordmark is lowercase **jalara**, drawn from the **Inter Display ExtraBold** letter shapes and committed as vector outlines in the two `logo-wordmark*.svg` files. This means the exported logo renders consistently without font installation or web requests. Do not recreate the wordmark with browser text when the supplied outlined SVG can be used.

Outside the artwork, write the proper brand name as **Jalara**.

## UI and documentation

Use **Inter** (or the normal application system UI font stack) for interfaces and technical documentation. Keep headings legible and body copy direct. Existing JVST applications or derived products may use their own typographic identity.

Example CSS:

```css
font-family: Inter, ui-sans-serif, system-ui, -apple-system,
    BlinkMacSystemFont, "Segoe UI", sans-serif;
```

Use a monospace stack for code, commands and identifiers.

## Editorial voice

Prefer short, functional language focused on what the application enables. Avoid inflated marketing jargon. The brand positioning statement belongs in descriptions, not inside the logo artwork.
