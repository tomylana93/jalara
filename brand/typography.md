# Jalara Typography

The official Jalara wordmark is **custom lowercase geometric lettering stored as SVG paths**. It is independent of installed fonts and must never be recreated from a fallback font for official brand materials.

The displayed wordmark is `jalara`; in prose, write **Jalara**.

For surrounding UI and technical documentation, **Inter** or the system font stack is recommended. Code should use a readable monospace font. Do not bundle any font binaries into this assets repository.

Brand voice: clear, functional and restrained. Descriptive marketing copy belongs outside the logo.
